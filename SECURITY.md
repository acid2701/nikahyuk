# Security Policy

## Supported Versions

We release patches and security updates for the current active release line.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of NikahYuk and the privacy of event data seriously. If you discover a security vulnerability, please do NOT report it via a public GitHub issue.

Instead, please report the vulnerability privately by:
- Creating a [Private Security Advisory](https://github.com/acid2701/nikahyuk/security/advisories/new) on GitHub.
- Or contacting the primary maintainer directly.

Please include:
1. Description of the issue and potential impact.
2. Steps to reproduce or proof-of-concept.
3. Suggested mitigation if available.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.

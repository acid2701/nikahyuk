# Contributing to NikahYuk

Thank you for your interest in contributing to NikahYuk! We welcome community contributions from developers, designers, and organizers.

## Code of Conduct
We are committed to providing a welcoming, inclusive, and harassment-free environment for everyone. Please be respectful and constructive in all issues and pull requests.

## How Can I Contribute?

### Reporting Bugs
- Check the [existing issues](https://github.com/acid2701/nikahyuk/issues) before opening a new one.
- Provide a clear, descriptive title and steps to reproduce the issue.
- Include information about your operating system, browser, and Node.js version.

### Suggesting Enhancements
- Open an issue explaining the proposed feature and why it would be valuable.
- Detail the desired user experience and potential architectural impacts.

### Submitting Pull Requests
1. Fork the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Ensure existing tests pass:
   ```bash
   npm test
   ```
4. Test the production build:
   ```bash
   npm run build
   ```
5. Commit your changes using descriptive commit messages (following conventional commits, e.g., `feat: ...`, `fix: ...`, `docs: ...`).
6. Push to your fork and submit a Pull Request to `main`.

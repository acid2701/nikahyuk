# Product Requirements Document (PRD)

## Project Name: Wedding & Event Companion SaaS
**Version:** 2.1.0 (Definitive Production Specification)  
**Status:** Approved for Implementation  
**Target Environment:** aaPanel (Node.js/PM2/Docker) + Supabase (PostgreSQL 15+) + Cloudflare R2  
**Target Market:** Indonesia (Multi-event cultural weddings, intimate weddings, family-coordinated events)  
**Monetization Model:** Free / Voluntary Donation (KlikQRIS Static Tip Jar)

---

## 1. Product Overview & Strategic Objectives

Wedding & Event Companion SaaS adalah platform web-based kolaboratif yang mengorkestrasi seluruh siklus persiapan pernikahan dari fase pra-nikah (Lamaran, Pengajian, Siraman, Midodareni) hingga hari-H (Akad Nikah, Resepsi Pria, Resepsi Wanita, dan acara adat lainnya).

### 1.1 Core Value Propositions
* **Zero-Friction Deployment & Config:** Kredensial Cloudflare R2, limit ukuran/MIME type upload, target kompresi WebP/PDF, dan jadwal backup dikontrol dinamis via UI database Superadmin tanpa perlu *redeploy* atau memodifikasi file `.env` server.
* **Sovereign Financial Privacy:** Pemisahan anggaran mutlak per pihak keluarga (Pria vs Wanita) tanpa penggabungan otomatis paksa.
* **Multi-Tier Dynamic RBAC:** Template izin global dari Superadmin dipadukan dengan *custom granular overrides* oleh Pengantin (Owner) untuk masing-masing Wedding Organizer (WO) atau panitia keluarga.
* **Battle-Tested Field Operations:** Live rundown dengan *audio/lighting cues*, pergeseran waktu 1-klik (*Shift Timeline*), check-in multi-perangkat real-time anti-bentrok klaim souvenir, dan registrasi kilat tamu *walk-in*.
* **Zero Cold-Start:** Penyediaan *Starter Presets* bawaan (rundown, pos anggaran ideal, template WhatsApp) yang siap pakai dan dapat dikustomisasi total.
* **Privacy & User Sovereignty:** Ekspor mandiri seluruh database dan lampiran berkas ke dalam satu file `.zip` serta penghapusan akun permanen tanpa birokrasi konfirmasi admin.
